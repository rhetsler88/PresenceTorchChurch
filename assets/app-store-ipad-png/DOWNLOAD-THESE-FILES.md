# Download iPad screenshots (full size — not from chat)

Pictures **saved from the Cursor chat** are usually **small previews**, not
2064×2752. App Store Connect then drops them with **no error**.

Download the **real files** (right‑click → Save Link As, or open and download):

**2064 × 2752 (use this set)**

1. [01-signin.png](https://raw.githubusercontent.com/rhetsler88/PresenceTorchChurch/cursor/app-store-signin-screenshots-e0f6/assets/app-store-ipad-png/ipad-13-inch-2064x2752/01-signin.png)
2. [02-daily-code.png](https://raw.githubusercontent.com/rhetsler88/PresenceTorchChurch/cursor/app-store-signin-screenshots-e0f6/assets/app-store-ipad-png/ipad-13-inch-2064x2752/02-daily-code.png)
3. [03-talk.png](https://raw.githubusercontent.com/rhetsler88/PresenceTorchChurch/cursor/app-store-signin-screenshots-e0f6/assets/app-store-ipad-png/ipad-13-inch-2064x2752/03-talk.png)

Save all three into one folder on your **external drive**.

## Check before you upload (Mac)

1. Click one file → **File → Get Info** (or ⌘I).
2. **Dimensions** must say **2064 x 2752** (not 800×600 or similar).
3. **Size** should be roughly **200 KB – 600 KB** each (not a few KB).

If dimensions are wrong, you do not have the full file — use the links above again,
not the chat.
